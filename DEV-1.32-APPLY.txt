QuizTown DEV 1.32 적용 순서
1) Supabase Dashboard > SQL Editor에서 SUPABASE-DEV-1.32.sql 전체 실행
2) Windows에서 BUILD-QUIZTOWN-WINDOWS.cmd 실행
3) dist/QuizTown-Dev-1.32.0-Setup.exe 설치
4) 서로 다른 계정으로 클라이언트 2개 로그인
5) 양쪽 '현재 접속자'가 2명인지 확인
6) A에서 방 생성 -> B에서 방 표시 -> B 입장 확인
